# Modern Operate profile

Status: **Planned** — public specialisation boundary defined; detailed capability mapping requires owner review.

Modern Operate is a specialised application of the generic architecture to ongoing service delivery. It may add service commitments, operational workflows, domain packs, delivery roles and customer-specific configurations. It must reference core capability IDs rather than duplicate their definitions.

| Generic capability | Profile question |
| --- | --- |
| `l2-durable-workflows` | How does work resume across shifts and service interruptions? |
| `l3-domain-packs` | Which operational workflows can be packaged without forking the core? |
| `l5-value-cost-monitoring` | How are service performance and unit costs connected? |
| `c-oversight-capacity` | How many concurrent cases can a reviewer supervise effectively? |
| `dd-enterprise-systems` | Which operational system owns the work record? |

A profile contains only extensions: scope, domain language, policy parameters, capability references, evidence requirements and domain-specific tests. Client overlays belong in access-controlled repositories.

## Publication boundary

The owner’s reference architecture informed the five-layer, three-spine structure. The original deck, its detailed capability inventory, internal product names, assessments, research and client material are not included. This public page is a fresh generic interpretation, not a reproduction or endorsement of that material.

A detailed profile can be added only after its owner clears the specific content for public release. Do not add internal screenshots, customer data or copied assessment tables to public issues or pull requests.
