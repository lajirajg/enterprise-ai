## One knowledge base, several views

The [capability catalogue](catalogues/capabilities.md) holds canonical definitions. The [resource catalogue](catalogues/resources.md) holds each external resource once. Architecture, industry and learning views reference these records rather than making parallel copies.

**Coverage is deliberately broader than finished content.** [Content status](roadmap.md) distinguishes the initial framework from planned deep dives. This is a learning architecture, not a claim of product coverage or a certified control framework.
